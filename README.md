# Kedi Kuyruk Yakalama Teoremi

## Giriş

Bu repository, modern fiziğin ve bilgisayar biliminin en önemli problemlerinden birini ele almaktadır: **Bir kedi kendi kuyruğunu yakalayabilir mi?**

Cevap: Hayır. Asla. Matematiksel olarak imkansız.

## Bilimsel Temel

1. Kedi döner
2. Kuyruk da döner
3. Göreceli hız sıfırdır
4. Sonsuz döngü başlar
5. Evren katlanmaz, sadece kedi yorulur

## Kullanım

```bash
python kedi.py
```

**Uyarı:** Bu program gerçek bir kedi içermez. Eğer kediniz varsa, lütfen onu rahat bırakın.

## Katkıda Bulunma

Eğer kedinizin kuyruğunu yakaladığını iddia ediyorsanız, lütfen video kanıtı gönderin. Muhtemelen rüya görüyorsunuz.
